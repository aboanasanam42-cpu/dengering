## ✨ المميزات الرئيسية للتطبيق

### 1. 🔢 قسم الأسس والجذور (Exponents & Radicals)
- **حساب الأسس**: الأسس الموجبة، السالبة، والكسرية بدقة متناهية مع توضيح قوانين الأسس المستخدمة.
- **تبسيط الجذور**: تحليل الأعداد واستخراج العوامل الأولية وتبسيط الجذور التربيعية والتكعيبية والأعلى مع الخطوات التفصيلية.
- **حل المعادلات الأسية**: إيجاد قيم المتغيرات المجهولة في المعادلات الأسية المختلفة.

### 2. 📐 قسم النسب المثلثية وفيثاغورس (Trigonometry & Pythagoras)
- **نظرية فيثاغورس**: حساب الوتر أو أي من ضلعي القائمة بدقة وحساب المساحة والمحيط.
- **الدوال المثلثية**: حساب الجيب ($\sin$)، جيب التمام ($\cos$)، والظل ($\tan$) بالدرجات والراديان.
- **زوايا الارتفاع والانخفاض**: حل مسائل تطبيقات الزوايا في الحياة الواقعية.
- **رسم هندسي تفاعلي**: رسم فوري للمثلث القائم مع تحديد الزوايا والأضلاع بديناميكية تامة.

### 3. 🔺 قسم تشابه المثلثات (Triangle Similarity)
- **معامل التشابه**: حساب نسبة التشابه بين مثلثين بدلالة الأضلاع المتناظرة.
- **تناسب الأطوال والمحيطات والمساحات**: استنتاج المحيطات ونسب المساحات تلقائياً.
- **مخطط هندسي توضيحي**: عرض مرئي للمثلثات المتشابهة لتسهيل فهم العلاقات الهندسية.

### 4. ⚖️ قسم النسبة والتناسب والتقسيم التناسبي (Ratio & Proportion)
- **حل مسائل التناسب**: إيجاد الحد المجهول في التناسب باستخدام الضرب التبادلي (طريقة المقص).
- **التقسيم التناسبي**: توزيع المبالغ، التركات، الحصص، والميراث وفق نسب معلومة مع جدول تفصيلي لنصيب كل طرف.

### 5. 🤖 المساعد الرياضي الذكي (Gemini AI)
- إمكانية الاستفسار عن أي مسألة رياضية أو شرح القوانين والحصول على تحليل دقيق ومبسط خطوة بخطوة باللغة العربية.

### 6. 📄 التقارير والمشاركة (Export & Share)
- **تصدير PDF**: توليد تقارير رسمية أنيقة بصيغة PDF تحتوي على بيانات المسألة، الرسوم، والخطوات الكاملة، جاهزة للحفظ أو الطباعة.
- **تصدير Excel (.csv)**: حفظ البيانات في جداول إلكترونية متوافقة مع جميع برامج الجداول وتدعم اللغة العربية (`UTF-8 BOM`).
- **مشاركة واتساب فورة**: إرسال الحل والتقرير فوراً عبر واتساب لرقم المطور (`771124103`) أو أي رقم يتم اختياره.

### 7. 🕒 سجل التاريخ والمفضلة (History & Persistence)
- قاعدة بيانات محلية سريعة لحفظ كل العمليات الحسابية السابقة.
- إمكانية البحث والفلترة حسب التاريخ أو نوع المسألة واسترجاع النتائج بنقرة واحدة.

## 🔐 إعدادات المتغيرات والسرية في GitHub Actions (Secrets)

تم ربط المستودع بنظام البناء الآلي **GitHub Actions**، ويقوم بسحب وقراءة كافة المتغيرات السرية التي قمت بإضافتها في إعدادات المستودع (`Settings -> Secrets and variables -> Actions`):

| اسم المتغير السري (Secret Name) | الوظيفة واستخدامه في النظام |
|----------------------------------|------------------------------|
| `GEMINI_API_KEY` | مفتاح واجهة برمجة تطبيقات Google Gemini AI لإجراء التحليلات الرياضية الذكية. يتم حقنه تلقائياً في ملف `.env` و `BuildConfig`. |
| `KEYSTORE_BASE64` | ملف مخزن مفاتيح التوقيع (`.jks` / `.keystore`) مشفر بنظام Base64. يقوم الأكشن بفك تشفيره وبناء تطبيق موقّع رسمياً. |
| `KEYSTORE_PASSWORD` | كلمة المرور الرئيسية لمخزن المفاتيح (`storePassword`). |
| `KEY_ALIAS` | الاسم المستعار للمفتاح الخاص داخل الكي ستور (`keyAlias`). |
| `KEY_PASSWORD` | كلمة مرور المفتاح الخاص المستعار (`keyPassword`). |

## 🚀 سير عمل البناء الآلي (GitHub Actions Workflow)

عند رفع أي كود (`git push`) أو إنشاء إصدار جديد (`Tag: v1.0.0`):
1. يتم تنزيل الشيفرة البرمجية وإعداد بيئة `Java JDK 17` و `Android SDK`.
2. يتم قراءة المتغير `GEMINI_API_KEY` وإنشاء ملف `.env` الداعم للأمان.
3. يتم فك تشفير `KEYSTORE_BASE64` واستخراج ملف الكي ستور.
4. يتم استدعاء Gradle لبناء التطبيق بتوقيع رسمي باستخدام `KEYSTORE_PASSWORD` و `KEY_ALIAS` و `KEY_PASSWORD`.
5. في حال استخدام `apksigner`، يتم التأكد من توثيق التوقيع (V1 & V2 Scheme).
6. يتم رفع ملف الـ APK النهائي كأصل قابل للتحميل في **Artifacts** وفي **GitHub Releases**.

## 🛠️ البناء اليدوي المحلي (Local Development)

### المتطلبات الأساسية:
- **Android Studio** (Koala / Ladybug أو أحدث)
- **JDK 17**
- **Android SDK API 34+** (الحد الأدنى المدعوم Min SDK: 24)

### خطوات التشغيل:
1. استنسخ المستودع:
   ```bash
   git clone https://github.com/aboanasanam42-cpu/dengering.git
   cd dengering
   ```
2. انسخ ملف المتغيرات وأضف مفتاح Gemini الخاص بك:
   ```bash
   cp .env.example .env
   # قم بتحرير .env وضع مفتاحك: GEMINI_API_KEY=your_key_here
   ```
3. قم ببناء التطبيق:
   ```bash
   ./gradlew assembleDebug
   ```
   أو لإنشاء نسخة الإصدار:
   ```bash
   ./gradlew assembleRelease
   ```
