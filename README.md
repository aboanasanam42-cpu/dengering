# 📐 تطبيق حلول الرياضيات المتطورة (Math Solver)

تطبيق أندرويد متكامل وشامل لحل المسائل الرياضية المعقدة والخطوات التعليمية المفصلة، مع التوضيح بالرسوم الهندسية البيانية والتصدير المباشر لملفات PDF وجداول Excel ومشاركتها عبر الواتساب.

---

## 👥 فريق العمل والإشراف
* **تصميم وبرمجة وتطوير:** الدكتور / مالك الرميمة (هاتف: 771124103)
* **فكرة المشروع:** الأستاذ / محمد الرميمة
* **مصحح فكرة:** الأستاذ / مطهر الرميمة

---

## 🌟 ميزات وأقسام التطبيق الرئيسية

### 1. الأسس والجذور
* تبسيط الجذور التربيعية والتكعيبية وحساب القيم التقريبية بدقة.
* حل المعادلات الأسية خطوة بخطوة مع عرض القوانين الرياضية المطبقة.
* دعم العمليات المركبة على القوى والأسس الكسرية والسالبة.

### 2. النسب المثلثية وهندسة المثلث القائم
* حساب الجيب ($\sin$)، وجيب التمام ($\cos$)، والظل ($\tan$).
* حساب الوتر والأضلاع عبر **نظرية فيثاغورس**.
* حل زوايا الارتفاع والانخفاض للمسائل الحياتية.
* **رسم بياني هندسي تفاعلي** للمثلث يوضح الأضلاع، الزوايا، والقيم تلقائياً.

### 3. تشابه المثلثات
* إيجاد معامل التشابه وتناسب الأطوال ومحيطات المثلثات المتشابهة.
* عرض رسم هندسي ثنائي يوضح نسب التطابق والتشابه بصرياً.

### 4. النسبة والتناسب
* حل مسائل الضرب التبادلي وإيجاد المجهول في التناسب.
* مسائل التقسيم التناسبي وتوزيع الحصص التلقائي مع الخطوات المفصلة.

### 5. تصدير التقارير ومشاركة النتائج
* 📄 **تصدير ملف PDF:** مستند مرتب بصيغة PDF يحتوي على المسألة، المعطيات، والخطوات الكاملة جاهز للطباعة أو الحفظ.
* 📊 **تصدير ملف Excel (CSV):** جدول بيانات متوافق مع كافة برامج الجداول ومرمز بـ UTF-8 BOM لضمان سلامة اللغة العربية.
* 💬 **إرسال ومشاركة عبر واتساب:** زر مباشر لتنسيق الحل وإرساله بنقرة واحدة لأي رقم أو للرقم المخصص (771124103).

## 🔐 متغيرات وإعدادات الأمان (GitHub Secrets)

تم ربط خط سير العمل (CI/CD GitHub Actions) لقراءة الأسرار التالية تلقائياً عند بناء وإصدار ملف APK:

| اسم المتغير (Secret Name) | الوصف والاستخدام |
| :--- | :--- |
| `GEMINI_API_KEY` | مفتاح واجهة الذكاء الاصطناعي من Google Gemini API لتشغيل الخصائص الذكية وحل المسائل. |
| `KEYSTORE_BASE64` | ملف شهادة توقيع التطبيق Keystore مُشفر بصيغة Base64 لتوقيع نسخة الـ APK رسميًا. |
| `KEYSTORE_PASSWORD` | كلمة مرور مخزن المفاتيح (Keystore). |
| `KEY_ALIAS` | الاسم المستعار لمفتاح التوقيع (Key Alias). |
| `KEY_PASSWORD` | كلمة مرور المفتاح الخاص للتوقيع. |

## ⚙️ البناء والتثبيت الآلي (CI/CD)

يحتوي المستودع على خطة عمل جاهزة في `.github/workflows/build-apk.yml`:
1. يتم تشغيل البناء عند عمل **Push** إلى فرع `main` أو عند إضافة **Tag** جديد للإصدارات (مثل `v1.0.0`).
2. يقوم GitHub Actions بتجهيز بيئة Java، وإنشاء ملف `.env` ووضع `GEMINI_API_KEY` فيه.
3. يتم فك تشفير `KEYSTORE_BASE64` وتوقيع التطبيق بأمان تام دون إظهار المفاتيح.
4. يتاح ملف `APK` الجاهز للتثبيت كـ **Artifact** للتحميل المباشر أو ضمن صفحة **Releases**.
